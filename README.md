# Pesticide Guide

Interactive produce monitoring atlas and 2D food compass comparing official laboratory pesticide residue tests and Tufts University Food Compass 2.0 longevity nutrition scores for 69 familiar fruits, vegetables, and legumes across 9 international markets.

## Features
- **Interactive 2D Food Map**: Explore 69 produce items mapped across Pesticide Load vs Longevity Score in 4 quadrants.
- **Multi-Market Filtering**: Compare official data from US (USDA PDP), UK (PRiF), EU (EFSA), and Canada (CFIA).
- **Shopper's Guide**: Actionable organic vs conventional buying recommendations and 1% baking soda washing protocol.
- **SEO & Full Directory**: 69 dedicated static produce profiles with JSON-LD Dataset and FAQPage schemas.

## Tech Stack
- **Framework**: Next.js 16 (App Router, Turbopack, SSG)
- **Language**: TypeScript 7.0
- **Testing**: Vitest
- **Styling**: Native CSS with Glassmorphism, CSS Grid, and custom animations
- **Deployment**: Vercel
- **Feedback**: MakeThisBetter widget with a site-wide feedback board link

## Running Locally

npm install
npm run dev
npm test
