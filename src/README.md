# src
- 用途：前端应用程序源代码根目录，包含应用路由、UI 组件、业务逻辑与静态监测数据
- 关键入口：src/app/page.tsx, src/components/FoodExplorer.tsx
- 边界/依赖：依赖 Next.js 16 App Router、React 19 以及 Lucide/原生 CSS
> 一旦本目录内容变化，请更新本文件

## Files
- app/：Next.js App Router 页面路由与布局
- components/：可复用前端交互组件（如全屏 2D 罗盘图）
- lib/：核心数据转换、排序算法与类型定义
- data/：184,077 条官方实验室农残与营养基础快照数据
