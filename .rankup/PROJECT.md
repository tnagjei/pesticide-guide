# 项目定义

## 产品

- 名称：Pesticide Guide
- 一句话定位：比较果蔬农药残留监测数据与 Food Compass 2.0 营养评分的交互式食品指南。
- 目标用户：希望理解果蔬农残、购买有机食品优先级和数据来源的普通消费者。
- 核心问题：官方实验室数据复杂，消费者难以比较不同果蔬和市场的数据。
- 核心价值：把政府监测数据和营养评分整理成可浏览、可解释的食品目录与 2D 图表。
- 商业模式：待确认；当前代码未观察到支付流程。

## 目标

- 让用户能从首页进入食品目录、方法说明、来源和合规页面。
- 保持每个食品详情页可索引，并让数据来源和限制清晰可见。
- 通过 GSC 观察真实搜索曝光后再决定内容扩展方向。

## 非目标

- 不把项目自有排序称为 EWG 或 USDA 官方榜单。
- 不把相对评分解释为个人健康风险或医学建议。
- 不在没有数据和授权时扩展外链投放、支付或广告承诺。

## 约束

- 技术：Next.js 16 App Router、React 19、TypeScript、静态生成、原生 CSS。
- 业务：数据来自多个官方监测来源，页面必须保留方法、来源和限制说明。
- 合规与安全：`.gsc.json` 只保留 siteUrl；真实凭据不进入项目记忆或 Git。
- 本次范围：只初始化 `.rankup/`，不修改业务代码、不部署、不提交 Git、不执行外链提交。
